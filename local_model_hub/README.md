# Local Model Hub

Flutter Material 3 Expressive UI scaffold for managing local models and an OpenAI-compatible API gateway.

## Current scope

- Responsive Material 3 Expressive overview, model library, API keys, request activity, and settings screens.
- GGUF imports are copied into app-private persistent storage; Android launches the bundled ARM64 llama.cpp server through a foreground service, while desktop launches a configured `llama-server` executable.
- Local API gateway binds to `127.0.0.1:8080` and forwards OpenAI-compatible requests to the engine on `127.0.0.1:18081` on Android or `127.0.0.1:8081` on desktop.
- Bearer key authentication, per-key requests-per-minute limits, secure key storage, request logs, and upstream token usage accounting.
- GPU selection is passed as llama.cpp startup flags (for example `--n-gpu-layers auto`) and displayed as configured flags. Actual GPU use depends on the selected `llama-server` binary and backend build.

Android builds package an ARM64 PIE `llama-server` executable and run it in a foreground service with a persistent notification. Android runner files are generated by CI; iOS and Web do not support local engine launch.

## Run

Requires Flutter SDK 3.6 or newer.

```sh
flutter pub get
flutter run -d <device>
```
